# TypeSwitcher 2.1.0 — руководство

TypeSwitcher — переносимый помощник ввода для Windows 10/11 x64. Исправляет опечатки,
переключает раскладку RU/EN/UK, меняет регистр и выполняет личные правила замены.
Программа работает локально: интернет, учётная запись, облачные модели и телеметрия
для её работы не требуются. Среда выполнения .NET и словари входят в комплект.

## Запуск

Распакуйте весь архив `TypeSwitcher-2.1.0-win-x64.zip` в папку с доступом на запись
и запустите `TypeSwitcher.exe`. Держите EXE, DLL, `assets/` и `dict/` вместе.
Двойной щелчок по значку в трее открывает настройки, одиночный включает/выключает
обработку, правый открывает меню. Первый запуск строит локальные языковые кеши.

По умолчанию активны английский и русский. Для украинского добавьте раскладку в
Windows, затем включите **Українська** на странице **Языки** и сохраните настройки.

## Команды по умолчанию

| Команда | Сочетание |
|---|---|
| Отмена/возврат правки или ручная раскладка слова | Pause |
| Регистр текущего или последнего слова | Shift+Pause |
| Действия для последнего слова | Scroll Lock |
| Глобальная пауза / возобновление | Ctrl+Alt+P |
| Только отмена последней доступной правки | Ctrl+Alt+Z |
| Раскладка выделенного текста | Ctrl+Alt+L |
| Регистр выделенного текста | Ctrl+Alt+U |
| Транслитерация выделенного текста | Ctrl+Alt+T |

В разделе **Общие** можно назначить другие сочетания. Буквенные команды требуют
Ctrl, Alt или Win; функциональные клавиши могут использоваться отдельно. Backspace
в поле назначения снимает привязку, Esc отменяет захват. Одна команда не должна
занимать сочетание другой команды.

Опционально можно назначить одиночный левый/правый Shift или Ctrl для переключения
раскладки либо преобразования слова. Срабатывает короткое нажатие и отпускание:
другая клавиша, щелчок, прокрутка и долгое удержание отменяют действие. Украинский
AltGr используется для ввода символов, а не для запуска похожих сочетаний.

## Выделенный текст

Выделите слова или фразу в редактируемом поле и вызовите нужную команду.
Например, `ghbdtn vbh` преобразуется в `привет мир`. Если EN может означать RU или
UK, программа предлагает выбор с предпросмотром. Целевой язык можно задать явно
в разделе **Общие → Выделенный текст**.

Регистр меняется по кругу: строчные → ПРОПИСНЫЕ → Каждое Слово → строчные.
Транслитерация использует отдельные русскую и украинскую таблицы (`Щука` →
`Shchuka`, `Київ` → `Kyiv`). Обратное преобразование неоднозначно, поэтому
результат сначала показывается в предпросмотре.

Работа выполняется через UI Automation, без служебного копирования в буфер обмена.
Поддерживается одно непрерывное однострочное выделение до 2048 символов. Парольные,
доступные только для чтения, исключённые поля и терминалы не обрабатываются.
Если редактор не предоставляет подходящий интерфейс, программа сообщит об этом.
Перед записью повторно проверяются поле, выделение и актуальность ввода.

## Настройки автоматики

- **Уважать ручной выбор раскладки:** первое слово после внешнего переключения
  языка защищено от автоматических догадок. Явные текстовые подстановки пользователя
  продолжают работать. По умолчанию включено.
- **Английские опечатки:** отдельная выключенная по умолчанию опция на странице
  **Опечатки**. Используются поставляемые Hunspell и частоты EN; неоднозначные
  варианты оставляются при недостаточном отрыве лучшего кандидата.
- **Исправлять после паузы:** проверка текущего слова через 350–5000 мс, по умолчанию
  900 мс. Сама функция выключена до её выбора пользователем.
- **Раннее переключение:** после 4–12 букв может преобразовать префикс, если
  в исходном языке нет известных продолжений, а в целевом есть несколько.
  По умолчанию выключено; при сомнении ожидает окончания слова.
- **Контекстная проверка:** выключена / наблюдать / применять. Использует язык
  последних шести завершённых слов, а не копию поля или историю общения. Признаки
  живут в памяти до 30 секунд и сбрасываются при смене контекста. Наблюдение
  позволяет видеть предложения в проверочной песочнице без изменения базовых решений.

Эти режимы не обходят защиту паролей, приложений, стоп-слов и явного ручного выбора.
Состав языков RU/EN/UK учитывается при принятии решения; неоднозначность не заменяется
случайным выбором языка.

## Правила и проверка

На странице **Правила** сохраняется формат личных текстовых замен `что = на что`.
На странице **Правила раскладки** можно задать образец, исходный язык, целевую
раскладку, учёт регистра и действие **Переключать / Не переключать**.

Условия: целое слово, начало или вхождение. Точное совпадение сильнее начала,
начало сильнее вхождения; более длинный образец сильнее короткого. При равенстве
побеждает запрет. Стоп-слова имеют высший приоритет. Правила вступают в силу после
общей кнопки **Сохранить**.

Страница **Проверка** анализирует только введённый пользователем пример. Она
учитывает значения формы и незавершённые правки личных списков, показывает причины,
кандидатов, частоты и предложения контекста. Пример не сохраняется автоматически;
файл создаётся только по кнопке **Экспорт отчёта**.

## Удобство и история

- В исключения можно добавить выбранное окно, работающее приложение или `.exe`.
- Цветная отметка рядом с параметром показывает отличие от значения по умолчанию.
  Кнопка с круговой стрелкой сбрасывает только этот параметр.
- Настройка **Показывать раскладку в трее** включает индикатор EN/RU/UK; язык можно
  выбрать через меню значка. Язык интерфейса на язык ввода не влияет.
- История записывает только исправления и откаты и включается отдельно. Лимит —
  10–10000 записей, по умолчанию 500. На странице **История** доступны просмотр,
  очистка и подготовка стоп-слова/правила по выбранной записи.
- **О программе** содержит описание, версию, сведения о данных и лицензии, а также
  ссылку на GitHub. Ссылка открывает внешний браузер только по нажатию пользователя.

Все страницы доступны на русском, английском и украинском. Язык и тема применяются
сразу; остальные правки — после **Сохранить**.

## Данные и перенос

Папка `data/` рядом с программой содержит настройки, личные словари, правила,
импортированные наборы, кеши моделей и включённую историю. При обновлении сохраняйте
её. Схема настроек 3 мигрирует старые схемы 1/2, сохраняя резервную копию
`config.json.v1.bak` / `config.json.v2.bak` и старые назначения клавиш.

Контекстная проверка не записывает слова на диск и не обучается на обычном вводе.
Сетевой загрузки моделей, проверки обновлений и отправки журналов в приложении нет.
На GitHub файлы новой версии загружаются пользователем отдельно.
