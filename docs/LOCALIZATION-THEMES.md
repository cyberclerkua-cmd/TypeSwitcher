# Локализация и темы

## Настройки

Используются существующие поля схемы 2:

```json
{
  "general": {
    "language": "uk",
    "theme": "system"
  }
}
```

`language`: `ru`, `en`, `uk`. `theme`: `light`, `dark`, `system`.
Неизвестные значения нормализуются к прежним значениям по умолчанию (`ru`, `dark`).
Языки анализа текста находятся в отдельной секции `languages`.

## Текст

`Localization/L.cs` использует русские исходные сообщения как идентификаторы и
встроенные JSON-каталоги `Localization/en.json`, `Localization/uk.json`.
Каталоги встраиваются в сборку, в том числе single-file; отдельная загрузка не нужна.

- `L.T(message, args)` — сообщения, форматируемые в момент операции.
- `L.Bind` / `.Localize` — живые WPF-привязки для заголовков, подписей, подсказок и статусов.
- `UiChoice` — стабильный идентификатор и обновляемая подпись для списков.
- Имена пользовательских словарей и редактируемый текст не являются ключами перевода.
- `CurrentCulture` потока не изменяется: числовые настройки и лингвистическое ядро независимы от UI.

При добавлении сообщения обновлять оба JSON-каталога. Тесты проверяют одинаковые ключи,
параметры `{0}`/`{1}`, отсутствие пустых переводов и отсутствующих ключей при построении окон.

## Цвета

`Tray/Theme.cs` содержит светлую и тёмную палитры. Для программно создаваемых элементов
используются общие UI-кисти; XAML-шаблоны используют DynamicResource. Поэтому цвета
меняются без пересоздания редакторов и потери введённого текста.

`general.theme=system` читает `AppsUseLightTheme` и отслеживает UserPreferenceChanged,
WM_SETTINGCHANGE и WM_THEMECHANGED. Заголовки окон обновляются через DWM.
Явные light/dark не зависят от последующих изменений системной темы.

`UiPreferences` сохраняет только выбор интерфейса в текущем конфиге и обновляет представление.
Кнопка темы и подменю трея используют одну реализацию; изменение оформления не перезагружает словари.

## Проверка

- `LocalizationTests`: каталоги, форматирование, политика системной темы, независимость языков ввода.
- `UiSmokeTests`: все страницы и окна в RU/EN/UK × light/dark/system, пункты меню, сохранение,
  реакция на сообщение Windows при подменённом источнике системного цвета (без изменения Windows).
- `TypeSwitcher.Acceptance --phase appearance`: настоящие окна, девять комбинаций, пиксели фона,
  иконка темы, сохранность незавершённых полей, перезапуск и английская ошибка импорта.
