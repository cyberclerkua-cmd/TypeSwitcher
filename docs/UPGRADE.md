# Обновление TypeSwitcher

Настройки, пользовательские словари, правила и импортированные наборы находятся в
`data/` рядом с исполняемым файлом. При обновлении в той же папке сохраняйте этот каталог.

Для переноса в новую папку сначала завершите предыдущую копию приложения и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy RemoteSigned -File tools/migrate-data.ps1 -SourceDirectory "C:\Apps\PreviousApp" -DestinationDirectory "C:\Apps\TypeSwitcher"
```

Инструмент копирует data/ через промежуточный каталог, сверяет SHA256 каждого файла
и публикует копию атомарным переименованием. Существующая целевая data/ не перезаписывается.
Исходная data/ остаётся на месте.

`data/upgrade-history.json` хранит явно указанные пути прежних исполняемых файлов.
По ним приложение обнаруживает ещё работающую предыдущую копию и обновляет только
соответствующие записи автозапуска. Имена предыдущих продуктов в исходники не зашиваются.

Стандартные старые пути значков `icon_blue.png` / `icon_red.png` заменяются новыми.
Пользовательские пути значков сохраняются. Структура файлов личных словарей не меняется.

Вариант развёртывания с миграцией:

```powershell
.\deploy.ps1 -Publish -Target "C:\Apps\TypeSwitcher" -PreviousDirectory "C:\Apps\PreviousApp"
```
